# 🛍️ HK-STORE Chlef (`HK-STORE.dz`)

> Plateforme E-Commerce Haute Performance pour **HK Store Chlef**  
> Spécialisée en Accessoires de Mode, Horlogerie, Coffrets Cadeaux, et Prêt-à-porter en Algérie (Livraison 58 Wilayas).

---

## 🚀 Stack Technique

* **Framework :** Next.js 15 (App Router) + TypeScript
* **Styling :** Tailwind CSS
* **Base de Données & Temps Réel :** Supabase (PostgreSQL Cloud)
* **Logistique :** 1-Clic COD Checkout (58 Wilayas) + Intégration Yalidine DZ
* **Déploiement :** Vercel
